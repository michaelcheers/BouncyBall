Bouncy Ball

A Physics-Based Ball Simulation Game

Getting Started

Welcome to Bouncy Ball! Control a ball that moves based on physics simulation with velocity, drag, and gravity.

Quick Start: Click "New Game", enter a world name, and press Enter to start playing!

Main Menu

  • New Game - Start a fresh game session
  • Load Game - Load a previously saved game (stored in browser localStorage)
  • Quit - Exit the game

Game Display (HUD)

The game displays real-time statistics in the top-right corner:

Speed: 5.23pix/frame
Maximum Speed: 12.45pix/frame
Elevation: 340pix
Distance: 1523.67pix
Gravity: 0.0100pix/frame
  • Speed - Current velocity magnitude
  • Maximum Speed - Highest speed achieved this session
  • Elevation - Height from bottom of screen
  • Distance - Total distance traveled
  • Gravity - Current gravity value (only shown if non-zero)

Saving & Loading

The game auto-saves when you return to the main menu. All saves are stored in your browser's localStorage.

Paste from Clipboard: When entering world names, use Ctrl+V to paste text.

Load Game Menu

  • Left Click - Load the selected save
  • Right Click - Open options (Play, Delete, Rename)
Note: Saves are stored in browser localStorage. Clearing browser data will delete your saves!

Pro Tips

  • Combine bouncy mode (V) with gravity (N) for satisfying physics!
  • Use trail mode (4) to create cool patterns as you move
  • Try invisible ball (I) with dynamic background (PageDown) for a challenge
  • Enable edge death (Shift) to add stakes to your gameplay
  • Use CPU multiplayer (Windows key) to have a ball follow your movements
  • The background color is calculated using: cos(x * 0.01) for red and cos(y * 0.01) for green
